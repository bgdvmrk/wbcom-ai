Модель выбирайте по самым частым характеристикам топа

Емельянов, Мухаметзянов (трижды), Сантурян: разложите товар на признаки и соберите модель из самых частых характеристик топа. Емельянов собирает «лего-конструктор» из характеристик топ-100 (пример — короткая прямая кожаная юбка с высокой посадкой без разреза), Сантурян для технических товаров сравнивает характеристики топ-50/100 конкурентов.

Как применить

  1. Выгрузите топ-100.
  2. Посчитайте частоту характеристик.
  3. Соберите модель.
