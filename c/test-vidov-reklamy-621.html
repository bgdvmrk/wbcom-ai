Запустите несколько видов рекламы с малым бюджетом и оставьте лучший

Ведерников: все виды рекламы по очереди по 1–3 тыс. ₽, ставку выше минимальной на 10–30%. Для новинки сравнивайте стоимость корзины, а не CTR: единая 16 заказов с кликом по 3 ₽ против 2 заказов на CPC.

Как применить

  1. Запустите виды по очереди.
  2. Продолжайте с самым эффективным.
