Стратегию рекламы Ozon подбирайте тестом по своему магазину, универсальной нет

Невталиев говорит, что настроек почти не осталось и рабочую связку (авто, средняя стоимость клика, ОЗЗ) нужно подбирать тестом по своему магазину. Кулешова выбирает стратегию по ситуации (бюджет, воронка), Жаркова — по отчёту запросов: если верхушка ключей нерелевантна, только средняя стоимость клика. Кулагина советует тестировать разные биддеры: рабочий может перестать работать через месяц.

Как применить

  1. Тестируйте стратегии на разных артикулах.
  2. Выбирайте по отчёту запросов.
  3. Периодически перепроверяйте автоматизацию.
