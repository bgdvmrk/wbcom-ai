База знаний

Выкупать нужно по конкретному поисковому запросу, а не по артикулу

Софронова (3 выступления) и Воробьев: выкуп по нужному запросу даёт быстрый буст именно по нему; Воробьев советует длинный релевантный запрос из облака слов ниши, чтобы вырасти сразу по группе ключей. Елена: выкупы по релевантным ключам вытаскивают в топ, а чем ниже позиция по ключу, тем меньше трафика и заказов.

Как применить

  1. Выберите запрос, где хотите расти.
  2. Заходите в карточку через поиск по этому запросу.
  3. Отслеживайте динамику позиции по нему.
