Расчёт поставок на Ozon можно автоматизировать Excel-шаблонами и бесплатным сервисом Муая

Янцов описывает два инструмента: Excel-шаблоны состава по каждому кластеру с ограничениями складов из аналитики планирования поставок Ozon, и сервис moai.ru, пока только для Ozon. Сервис в бета-версии показывает остатки и дни покрытия по кластерам, считает план отгрузки и выгружает Excel и шаблоны для Ozon; автосоздания поставок нет.

Как применить

  1. Подгрузите ограничения складов из аналитики Ozon.
  2. Автоматизируйте расчёт по кластерам и среднесуточным продажам.
