База знаний

Разведите артикулы склейки по ролям: у каждого свой тип рекламы и зона показа

Денисова советует направлять на каждый артикул свой тип рекламы (локомотив на CPM в топ, второй на CPC ниже, третий только в полки) и давать цветовому варианту единую кампанию с ключами. Мощенок: у каждой карточки своя релевантная зона (запрос, полки, подборки). Николай: на первую склейку гнать трафик, на вторую меньше, на третью без рекламы держать цену повыше.

Как применить

  1. Распределите по артикулам разные запросы и зоны.
  2. Следите, чтобы карточки не конкурировали друг с другом.
  3. Для каждого артикула держите свой план продаж.
