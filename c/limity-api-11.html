Перед подключением ИИ к API WB и Ozon изучите лимиты запросов

Подскребаев дважды предупреждает: у каждого метода API свои лимиты, частые запросы блокируют токен, поэтому документацию читают до автоматизации, а ключ дают на чтение.

Как применить

  1. Изучите частоту запросов по каждому методу.
  2. Выдавайте ключ только на чтение.
  3. Данные, которые API не отдаёт, выгружайте файлом.
